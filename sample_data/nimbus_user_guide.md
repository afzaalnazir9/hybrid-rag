# Nimbus Notes — User Guide

> Nimbus Notes is a fictional note-taking app invented for this demo.

## Getting started

Nimbus Notes runs on Windows, macOS, Linux, iOS and Android. After installing the app, sign in with an email address and choose a workspace name. Each account starts with one workspace called "Personal". You can create up to 10 workspaces on the Free plan and an unlimited number on the Pro and Team plans.

Notes are organised into notebooks, and notebooks live inside a workspace. A note can belong to only one notebook at a time, but it can carry any number of tags. Tags are shared across all notebooks in a workspace.

## Writing notes

The editor supports Markdown. Type `#` followed by a space to start a heading, `-` for a bullet list, and three backticks to start a code block. Press Ctrl+Shift+K (Cmd+Shift+K on macOS) to insert a checklist item.

Images and PDF files can be dragged into a note. On the Free plan each attachment may be up to 25 MB; on Pro and Team plans the limit is 250 MB per attachment.

## Search

The search bar searches note titles, note bodies and the text inside attached PDFs. Put a phrase in double quotes to match it exactly. Use `tag:` to filter by tag, for example `tag:meeting budget`. Use `nb:` to limit the search to one notebook, for example `nb:Research`.

## Offline mode

Nimbus Notes keeps a full copy of every notebook you have marked "Available offline". Changes made while offline are stored in a local queue and uploaded automatically when the connection returns. If the same note was edited on two devices while both were offline, Nimbus keeps both versions and adds the suffix "(conflicted copy)" to the older one.

## Sharing

Any note can be shared with a read-only public link. On the Team plan, notebooks can also be shared with teammates, who can be given one of three roles: Viewer, Editor or Owner. Only an Owner can delete a shared notebook or change other members' roles.

## Version history

Nimbus saves a new version of a note every time you stop typing for 30 seconds. Free accounts keep version history for 7 days, Pro accounts for 90 days and Team accounts for 1 year. To restore an older version, open the note menu and choose "Version history".

## Keyboard shortcuts

| Action | Windows / Linux | macOS |
|---|---|---|
| New note | Ctrl+N | Cmd+N |
| Quick search | Ctrl+P | Cmd+P |
| Toggle sidebar | Ctrl+\ | Cmd+\ |
| Insert checklist | Ctrl+Shift+K | Cmd+Shift+K |
| Focus mode | F11 | Cmd+Ctrl+F |
